# Money Planner

Personal income, expense and investment planning app for iPhone and Android.

- Runs in the browser and installs to the home screen (Safari: Share > Add to Home Screen; Chrome: Install app).
- Works offline.
- All entries are stored only on the device, in the app's local storage. Nothing is sent to any server.
- Back up and restore from Settings (a .json file you keep in Files or iCloud Drive).
- Fill an entry from a bank SMS: copy the SMS, tap Add, then "Fill from a bank SMS". The message is read on the phone and never sent anywhere.
